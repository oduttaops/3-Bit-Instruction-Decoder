3-Bit Instruction Decoder

Interactive demonstration of a 3-to-8 line decoder with an enable input. Change the four switches and observe the selected control output.

1. Input controls

Tap a switch to change its logic level between 0 and 1.

Current opcode 000 Decimal:0
Decoder status ENABLED C0 · ADD is active
When E = 1, exactly one output is HIGH. When E = 0, all eight outputs are LOW, regardless of the opcode.

4. Logic equations

Each output is the AND of the enable signal and the required opcode bit pattern. A prime (′) means NOT.

C0 = E · O2′ · O1′ · O0′
C1 = E · O2′ · O1′ · O0
C2 = E · O2′ · O1 · O0′
C3 = E · O2′ · O1 · O0
C4 = E · O2 · O1′ · O0′
C5 = E · O2 · O1′ · O0
C6 = E · O2 · O1 · O0′
C7 = E · O2 · O1 · O0

5. How to test

  1. Keep Enable E = 1.
  2. Set the opcode to 000. Only C0 (ADD) should glow.
  3. Try 011. Only C3 (OR) should glow.
  4. Try 111. Only C7 (STORE) should glow.
  5. Set E = 0. All output indicators should turn off.

This is a browser-based logical simulation of the project, not a physical hardware circuit.
