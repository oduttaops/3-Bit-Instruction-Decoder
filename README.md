# 3-Bit-Instruction-Decoder
DESIGN AN INSTRUCTION DECODER CIRCUIT THAT DECODES A 3-BIT OPCODE FIELD INTO 8 DISTINCT OPERATION CONTROL SIGNALS. USE A 3-TO-8 LINE DECODER WITH AN ENABLE LINE TO ACTIVATE SPECIFIC ALU OR REGISTER CONTROL LINES. VERIFY THE ACTIVE CONTROL LINES FOR DIFFERENT 3-BIT OPCODE PATTERNS.
